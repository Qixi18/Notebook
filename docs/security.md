# 本地安全边界

- 应用默认只绑定 `127.0.0.1`；CORS 只允许本地 Web 端口。
- 上传继续校验扩展名、容器签名、大小和位置数；服务端生成存储文件名。
- 备份包拒绝绝对路径、`..` 和反斜杠成员；恢复写入空隔离目录。
- 外部课件、网页片段和会话历史作为不可信文本传给模型，不作为工具控制指令。
- `/config/status`、诊断和备份清单不返回密钥；`.env` 不进入备份包和前端构建。
- 用户笔记正文由版本号和 `user_locked` 保护；AI 建议需明确确认。
- 日志和错误应使用请求/任务 ID与错误码，避免记录完整课件、回答中的密钥或环境变量。
