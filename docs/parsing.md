# 资料解析能力

阶段二使用统一的 `ParsedDocument → ParsedPage → ParsedBlock` 契约。解析器只产生结构化结果和警告，任务 worker 负责把结果写入数据库，知识提取和检索使用已经提交的页面块。

| 格式 | 位置表达 | 当前能力 | 明确边界 |
|---|---|---|---|
| PPTX | 第 N 页、对象序号 | 文本框、标题、表格、字体/加粗信号 | 图片、公式对象会保留警告；空页标记 OCR 候选 |
| PDF | 第 N 页 | 使用文字层提取文本 | 扫描页不伪造文本，标记 OCR 候选；坐标暂不承诺 |
| DOCX | 章节/段落、表格序号 | 标题、段落、表格和图片对象提示 | DOCX 没有可靠固定页码，不显示臆造页码 |

上传服务检查扩展名、实际容器/签名、损坏状态和大小，先写临时文件，再原子改名到 `data/originals`。服务器生成存储文件名，客户端文件名只作为展示字段。

OCR 是独立的可选适配层。未设置 `NOTEBOOK_OCR_ENABLED=true` 时，扫描页和图片只显示“待 OCR”告警；不会把空文本当成解析成功，也不会产生虚假的引用。`GET /ocr/status` 会报告启用状态、依赖是否可用、页数上限和超时时间；OCR 调用超时或失败会保留候选告警。
