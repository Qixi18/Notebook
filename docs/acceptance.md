# 阶段三、四验收矩阵

| 能力 | 自动证据 | 浏览器证据 | 真实样本状态 |
| --- | --- | --- | --- |
| 跨讲提案与变更 | `test_phase_three_four.py`、知识提案 API | 知识树详情确认/拒绝 | 需要连续三讲人工标注 |
| 用户笔记保护 | 既有阶段一/二测试、`NoteSuggestion` 接口 | 笔记侧栏接受前查看差异 | 需要至少十条用户编辑笔记 |
| 持久答疑 | 会话创建、消息读取、幂等测试 | 答疑页会话下拉框和证据映射 | 需要真实模型/联网调用记录 |
| 课程隔离 | 会话、资料、反馈目标归属检查 | 切换课程后重新读取会话 | 需跨课程人工抽查 |
| 反馈 | 反馈目标校验、重复点击去重测试 | 答案“有帮助/需改进”按钮 | 需人工检查处理流程 |
| 备份恢复 | ZIP 清单、哈希、SQLite integrity、隔离恢复测试 | 首页导出入口；API 预览/恢复 | 需干净目录完整恢复演练 |
| 配置诊断 | `/config/status`、`/config/diagnostics` | 首页显示服务/OCR状态 | 外部服务按实际配置记录 |

测试通过、HTTP 200 或模拟模型不能替代真实回答质量、真实材料引用和外部服务费用记录。
